# Marketing & promotional collateral

Strategy docs and generation scripts/assets for Vehicle-Vitals marketing.
Moved here from `docs/` root on 2026-09-01 to keep the top-level docs folder
focused on product/engineering/release material.

| File | What |
|---|---|
| `MARKETING_STRATEGY.md` | Launch toolkit, channel strategy, asset checklist |
| `SOCIAL_MEDIA_STRATEGY_COMPREHENSIVE.md` | Per-platform social plan |
| `PROMOTIONAL_PODCAST_SCRIPT.md` | ~8-minute podcast script |
| `PROMOTIONAL_VIDEO_SCRIPT.md` | Promo video script (long + short cuts) |
| `AI_PODCAST_VIDEO_GENERATION_GUIDE.md` | How to turn the scripts into audio/video with AI tools |
| `AI_PODCAST_VIDEO_GENERATION.ipynb` | Notebook companion to the guide |
| `NOTEBOOKLM_INSTRUCTIONS.md` | Generated: NotebookLM steps |
| `podcast/podcast_clean.txt` | Generated: cleaned podcast transcript |

Website storyboards live at `docs/SOLUTION_STORYBOARDS.md` (kept in docs root
because `scripts/generate-storyboards-printable.mjs` reads it from there).
Its `SOLUTION_STORYBOARDS_PRINT.md` / `.pdf` outputs are generated and
gitignored — run the script to regenerate.
